# voice-pack

Text-to-speech voice model files (Supertonic 3, int8).

- Model: Supertonic 3 by Supertone Inc. (https://huggingface.co/supertone-oss-archive/supertonic-3)
- These files are the int8-quantized version converted by the sherpa-onnx project
  (https://github.com/k2-fsa/sherpa-onnx). They are a Derivative of the Model.
